A 4 KB Python chess engine: mailbox board, negamax with alpha-beta and iterative deepening on a fixed node budget, quiescence over captures, promotions and check evasions, a transposition table, killer + history move ordering, and a material + piece-square evaluation. It plays make.fun's tiny-chess-01 gauntlet through the trial env.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
